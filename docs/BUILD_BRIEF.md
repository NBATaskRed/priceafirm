# PriceAFirm build brief (condensed from the v2 product design, with the Oct 21 amendment)

PriceAFirm turns independent, confidence-labeled acquisition valuations of businesses already listed for sale into probabilistic crowd intelligence, and rewards useful contributions with a dynamically recalculated point balance that buyers spend to reveal original listing URLs.

## Locked decisions
- Universe: businesses listed for sale on approved, rights-cleared source sites. BizBuySell/BizQuest are blocked and must never be fetched.
- Question: cash-free, debt-free enterprise value (EV) of one immutable listing snapshot. NWC convention: earnings < $1M => NWC excluded, >= $1M => included; explicit terms override; unknown earnings => unresolved.
- Input: ONE central EV estimate + Low/Medium/High confidence. No PDFs, ranges or required rationale. Optional private "Why?" note with a no-confidential-data warning.
- Points: ONE live signed balance. Starts at 3 (WELCOME_GRANT). URL reveal costs exactly 1 point, once per business, free re-opens, free if the user submitted the URL themselves. Balance can go negative from later score revaluations; already-unlocked URLs stay unlocked; new reveals need balance >= 1.
- Score: each forecast gets a frozen [-L, +U] range (depends on confidence and n_eff before it). Score starts at 0 and is revalued whenever a later independent forecast arrives (peer-predictive proxy, NOT verified accuracy). Deltas post to the ledger immediately.
- Value businesses (Mode A): neutral facts only (headline, industry, region/state/metro, ask, revenue, earnings + type, snapshot date, number of independent valuations so far, max possible points per confidence). Sort by max High-confidence points or by fit. NEVER show crowd EV, EV/ask, direction or disagreement here.
- Find deals (Mode B): free natural-language search -> filter chips -> "N opportunities match" + opaque slots ("Opportunity 1: Preview free"). No identifying metadata on slots. Preview records an irreversible exposure BEFORE returning details, costs 0 points, makes the user ineligible for a scored blind valuation of that business. Preview shows industry, geography, size, ask, snapshot date, the number of independent valuations, and the crowd stats (median/mean EV, P10/P90, Pr(EV>ask), median/ask, evidence label, disagreement, concentration) when rights allow. Then "Reveal original listing URL - 1 point".
- AMENDMENT (Oct 21): there is NO minimum-contributor suppression threshold. Crowd statistics publish from the first valuation onward with an honest evidence label (0 = ask benchmark only, no crowd value; 1 = very limited; 2-4 = preliminary; 5-9 = moderate; 10+ = many). Every valued listing shows the number of independent valuations that contributed, in both the Value queue and the Find deals preview. Individual forecasts, confidence choices and identities are still never shown to other users.
- Add a listing: paste URL -> normalize -> allowlist check (blocked domains rejected before any fetch) -> dedupe against existing businesses -> safe fetch + field extraction (allowed domains only) -> show detected facts for correction -> immediately offer EV + confidence with the three point ranges -> "Submit URL + valuation" / "Submit URL only". URL-only earns nothing. If the user is already exposed to that business, offer no scored valuation and say why.
- Reputation: private provisional peer-predictive skill percentile; requires >= 5 scored forecasts; otherwise "Not enough evidence". No leaderboard.
- Terms acknowledgement before first contribution: own independent judgment, authorized sources only, no NDA-restricted info, no documents.
- Copy rules: "What do you think this business is worth?"; "Your balance may rise or fall as additional independent opinions arrive."; "Preview free: after preview, you won't be eligible to earn valuation points on this business."; "Reveal original listing URL - 1 point". Label all crowd numbers model-derived, not offers or observed prices. Never claim verified accuracy.
- Visual: serious financial intelligence tool with a game-like reward loop. Dark charcoal background, warm white text, ONE energetic accent (amber). Clear type hierarchy, concise money formatting ($2.9M, $680K). No confetti, no clip art, no exaggerated arrows. Keyboard operable, labeled controls, gains/losses not conveyed by color alone (use +/- signs and words).
- Nav: Find Deals, Value Businesses, Add a Listing, My Points, My Unlocked Listings. Mobile bottom nav: Find Deals, Value, Add URL, Points.
